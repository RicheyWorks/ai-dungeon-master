# First Light (flagship free pack)

The default reason to press play.

## Story

1. **The Sealed Letter** — cold open mid-chase; keep / burn / watch the letter  
2. **Noon in the Square** — public climax with skill checks, combat, **3 endings**

| Ending | How you get there |
|---|---|
| **The Tribune** | Speak in the square; reveal truth or ash |
| **The Open Blade** | Fight the counting-house captain |
| **The Pin** | Accept Veyra’s pact |

## Contents

- Quests: `first-light-cold-open`, `first-light-noon-square`  
- Campaign: `first-light-arc`  
- Factions: House Veyra, Street Shadows  
- Boss: Counting-House Captain  
- Key items: sealed letter, silver pin, letter-ash  

Engine prefers this pack as the **default opener** when loaded.
